# `gardenref.sty` — Standalone LaTeX Reference Package

A standalone, zero-dependency LaTeX package that turns mathematical definitions, theorems, and concepts into clickable hyperlinks resolving to your public Digital Garden website.

## Features

- **Autonomous Resolution**: Resolves references without requiring Obsidian or any background server to be running.
- **`hyperref` Compatibility**: Integrates cleanly whether `hyperref` is pre-loaded or loaded automatically.
- **Math Mode & Prose**: Works seamlessly on plain text, symbols, and math equations (e.g. `\gardenref{def-group-homomorphism}{$\varphi$ is a homomorphism}`).
- **Safe Fallback**: If a target reference is unpublished or missing from `gardenrefs.tex`, it renders the visible text as plain prose and emits a clear compiler warning rather than generating a dead link.
- **Draft Mode**: Supports `\usepackage[draft]{gardenref}` to suppress all hyperlink generation for print-ready drafts.

## Usage

```latex
\documentclass{article}
\usepackage{gardenref}

% The definitions are either auto-generated by the Obsidian plugin
% into gardenrefs.tex, or declared explicitly:
\declaregardenref{def-group-homomorphism}{https://obsidian.koltensserver.com/latex-references/def-group-homomorphism/}

\begin{document}
Let $f$ be a \gardenref{def-group-homomorphism}{homomorphism}.
\end{document}
```

## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `baseurl` | string | `https://obsidian.koltensserver.com` | Base website URL |
| `draft` | boolean | `false` | When true, renders text without hyperlinks |
| `colored` | boolean | `true` | When true, sets colored links |
| `linkcolor` | string | `blue` | Link color name |
